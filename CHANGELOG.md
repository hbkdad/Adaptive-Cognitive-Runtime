# Changelog

All notable user-visible changes to ACR will be documented in this file.

## Unreleased

### Added

- Fresh-evidence release engineering gate covering tests, migrations, security,
  benchmarks, CLI, API, clean installation, upgrade, and changelog readiness.
- Evidence-based security, performance, and architecture review roles.
- Measurement-first capability-gap discovery with derived build, defer, and
  reject decisions.
- Primary-source research-scout validation with complete topic coverage,
  explicit claim maturity, code and license status, ACR comparison, and
  benchmarkable adaptation boundaries.

### Security

- Release readiness now requires clean security evidence and GitHub immutable
  release protection before an external tag can be approved.
